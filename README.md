# Ro Ro Learning site

Static pages for Ro Ro Learning, served by GitHub Pages at https://lein0.github.io/roro-learning-site/

- `/privacy/` Privacy Policy
- `/terms/` Terms of Use
- `/support/` Support

Each page is standalone HTML (styles inlined), so it can be copied into another site as is. Edit the HTML, commit to `main`, and Pages republishes in about a minute. Keep the "Last updated" date in sync when wording changes. The same wording is mirrored in the app repo as PRIVACY_POLICY.md and TERMS.md.
